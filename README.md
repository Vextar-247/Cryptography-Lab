# Cryptography Laboratory Assignment

This repository contains the implementation of classical cryptographic algorithms in Python.

## Algorithms Implemented

1. Monoalphabetic Cipher
2. Caesar Cipher
3. Polyalphabetic (Vigenère) Cipher
4. Hill Cipher
5. Playfair Cipher
6. Rail Fence Cipher
7. Double Columnar Transposition Cipher

## Software Used

- Language: Python 3
- IDE: Visual Studio Code
